# SSIE 501 Black Box: the rule of each area, with proof

Group 5 · SSIE 501 Intro to Systems Science · Binghamton University · Fall 2026

The Black Box is a 20×20 grid that changes every step. This repository finds the rule behind each of its four areas, and backs every claim with code you can run.

**→ The model, written so anyone can rebuild it without our code: [MODEL_SPECIFICATION.md](MODEL_SPECIFICATION.md)**

**→ The evidence behind every claim: [REPORT.md](REPORT.md)**

![Real runs vs a box rebuilt from the rules](figures/07_simulation_vs_real.png)

## The answer in one table

| Area | Rule | Status |
|---|---|---|
| 3 (bottom-left) | The picked cell is redrawn from one fixed distribution (0: 36%, 1: 33%, 2: 17%, then roughly halving), ignoring the old value and the neighbours. | Solved |
| 4 (bottom-right) | Two random cells with different values swap only if neither loses same-value neighbours and one gains (8 neighbours, no wrap). | Solved |
| 1 (top-left) | Values move 0→1→2→3→4 or 9→8→7→6→5, or jump to the other branch's start when the cell's logic gate (a fixed rule over a few specific cells) points to the other half. | Solved |
| 2 (top-right) | 0 never changes. Rows 1-10 × columns 16-20 keep the smaller of the cell and a random cell of rows 11-20; rows 6-10 × columns 6-15 multiply by a random cell of that part and keep the last digit. | Solved |

Each step the areas update one after another (Area 1 first, Area 4 after Areas 2 and 3; C40, C53): Areas 1-3 pick one random cell and Area 4 picks two. The Area 1, 2 and 4 rules come from Marcus Washington's simulator and are tested on every held-out change (C35-C41).

## How everything is proven

- Every finding has an ID (C01-C53). Search for the ID in `analysis/` to find the code, and in `results/` to find the printed output.
- Rules were found on one dataset (61 runs) and tested on a separate held-out dataset (30 runs).
- `check_claims.py` re-tests all 54 claims automatically. Current status: **54/54 pass** ([results/claims_check.txt](results/claims_check.txt)).

## Run it

```bash
pip install -r requirements.txt
python run_all.py            # about 4 minutes; regenerates results/, figures/ and the claim check
```

The held-out shared dataset is included. Group 1's discovery runs (and Group 2's frames) must be placed in `data/` first; see [data/README.md](data/README.md). Each section of the report says which dataset each claim uses.
